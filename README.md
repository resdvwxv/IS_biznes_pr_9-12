## Структура проекта

```
repo/
├── pr_09/  — Практическая работа №9  (склад: StockItem, Warehouse)
├── pr_10/  — Практическая работа №10 (доставка: DeliveryPolicy, CARGO)

```

Каждая папка содержит:

| Файл / Папка | Назначение |
|---|---|
| `src/` | Исходный код Java |
| `data/` | Тестовые данные (CSV) |
| `out/` | Скомпилированные `.class` |
| `run_selfcheck.sh` | Скрипт компиляции и запуска SelfCheck |
| `DECISIONS.md` | Принятые архитектурные решения |
| `README.md` | Описание конкретной практической работы |
| `Практическая работа №N.docx` | Тетрадь (документ Word) |
