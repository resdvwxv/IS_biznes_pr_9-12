# DECISIONS

## 1. Map для позиций склада
Выбран `Map<String, StockItem>` с ключом `code`, потому что инвентарный код уникален,
а доступ по коду должен быть быстрым. Проверка дубликата выполняется через
`items.containsKey(item.getCode())`, а поиск - через `items.get(code)`, без линейного перебора.

## 2. Защитные копии и инкапсуляция коллекций
`findByCategory` возвращает новый список с копиями `StockItem`, `totalsByCategory` -
новый `EnumMap`, `categories` - новый `HashSet`, `movements` - `List.copyOf`.
`addItem` также сохраняет копию входного объекта. Поэтому изменение возвращённых
коллекций или исходного объекта после добавления не меняет внутреннее состояние склада.
