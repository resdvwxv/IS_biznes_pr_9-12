# DECISIONS

1. Чтение файла выполнено через `Files.newBufferedReader` и `try-with-resources`.
   Это потоковое чтение: ошибка одной строки обрабатывается внутри цикла, а ошибка
   открытия/чтения файла не маскируется и завершает операцию через `IOException`.

2. Политика дубликатов для варианта 6: повторный ИНН отклоняется с `ImportError`,
   первая запись остаётся в `ClientRepository`, импорт продолжается.
   Проверка размещена в `ClientImporter` после валидации и перед `repository.save(...)`.
